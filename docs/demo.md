# TIDE: 2-minute demo script

Record at 1440×900, navy theme, with the scanner running for at least a few hours so forecasts are unlocked. Pre-open the token page for the storm token once, so its forensics are cached and the waves land quickly on camera. Before recording, have a Telegram chat id ready for the alert.

| Time | Screen | Say / do |
| --- | --- | --- |
| **0:00** | Home, top | "Where is smart money flowing right now, across 38 chains?" Let the map sit for a beat. |
| 0:08 | Home, map | "Every hexagon is a chain the Nansen API lists. Amber means smart money is net buying, blue means net selling. The index is computed from Nansen's smart-money netflow against volume, scored against each chain's own history." Hover Base: the tooltip shows its CPI. Tap ⓘ: formula, inputs, the exact Nansen call. |
| **0:15** | Home, arcs | "These arcs are rotation fronts: the *same wallets* selling on one chain and buying on another within 12 hours. Measured, not guessed." Click the strongest front and show the wallet list. |
| 0:30 | Home, storm ticker | "Storm warnings: tokens where TIDE sees dump risk building." |
| **0:40** | Chain page (Base) | "Click into a chain." Barometer and 24h forecast: "every forecast shows its error rate next to it." The tide chart with its fan. Top inflows and outflows. |
| **1:00** | Token page (the Storm Warning token) | "A token in Storm Warning." Waves stream in. Wind rose: "who is moving it, by wallet segment and window: fresh wallets buying while smart traders sell is wind shear." Insider graph: "four wallets that share a funder hold 74% of supply." Tap the I chip's ⓘ. The 7-day odds card: "with the out-of-sample AUC next to it." |
| **1:25** | Home, anchor card (or "Ask the anchor" on the token page) | "Nansen's own agent reads TIDE's numbers and writes the weather report." Let the typewriter run. |
| **1:40** | Token page → Set storm alert | Paste the Telegram chat id and create it. Cut to the phone: the Nansen alert arriving. "It keeps watching after the tab closes." |
| **1:50** | Forecast Lab → Coverage | "Every model scored on data it never saw: AUC, calibration, the interval when evidence is thin." Then Coverage: "38 chains, 21 endpoints, and the live call counter." |
| 2:00 | Home | "TIDE. Built only on Nansen." |

# Address Labels

Retrieves all entity and behavioural labels associated with an address on a chain.

### Data Freshness & Historical Coverage

For data freshness and historical coverage, see [Data Coverage by Chain](/api/data-coverage.md); this endpoint follows it except where noted below.

* Returns the **current set of labels** for an address — there is no date-range parameter or historical look-back; labels reflect Nansen's latest label data and update within the standard live latency.

## Retrieve address label data

> Get labels for a wallet address. Returns non-premium labels only.\
> \
> Labels include ENS domains, behavioral labels, DeFi labels, CEX labels, and more.\
> Premium labels (smart money, alpha trader) are excluded from this endpoint.\
> \
> Use /api/v1/profiler/address/premium-labels to get all labels including premium ones.

# Broadcast a signed swap transaction

## Broadcast a signed swap transaction

> Broadcast a signed swap transaction.\
> \
> The caller is responsible for signing the transaction data returned by \`/api/v1/trade/quote\`.\
> \
> \- \*\*Solana:\*\* \`signed\_transaction\` is a base64-encoded serialized \`VersionedTransaction\`\
> \- \*\*EVM (Base):\*\* \`signed\_transaction\` is a \`0x\`-prefixed signed transaction hex\
> \
> The signed transaction is broadcast as-is; the response reports the resulting transaction hash and status.\
> \
> \*\*⚠️ This endpoint always broadcasts. There is no dry-run mode.\*\* Every call that passes\
> validation submits the transaction to the network, and a successful transaction is a real\
> executed trade that moves real funds. No request field prevents that.\
> \
> The transaction is always simulated first, and the broadcast is aborted if that simulation\
> fails — so a transaction that would revert does not reach the network. Simulation passing is\
> not a preview: it is what allows the broadcast to proceed.
